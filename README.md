# 学历证书存证系统重建

沿用去年的 Flask 网页、CMC 调用和长安链 Go 合约路线，分步恢复并改进为可在 Ubuntu 中运行、操作和录屏的系统。

业务以 `code.zip` 中更完整的比赛版为参考：SQLite 保存账号及证书全文，链上保存哈希和状态；本轮提供核心闭环、JSON 导出核验及本地审计，版本管理与批量功能属于后续扩展。

第五步真实合约验收已通过。用户随后反馈第六步全部网页操作均可用，核心系统已在 Ubuntu 完成业务验收，包括三角色登录、签发、核验、导出、撤销、记录与网页进程重启验证。退出按钮按用户要求保留在左栏底部，并修复左栏滚动。

Ubuntu 中的运行位置统一为 `/home/wsc/degree-cert-system`。Windows 当前资料目录下的同名文件夹是交付副本。

当前先按 [查询功能升级说明](docs/15-step06-search-upgrade.md) 同步网页更新：修复完整编号查询，并为查询机构提供姓名、学校、学号查询、签发时间排序和分页。随后按 [第七步备份与整机重启说明](docs/13-step07-backup-and-restart.md) 保存成果并验证冷启动恢复。第七步 ZIP 是增量工具包，不覆盖网页模板和样式。设计与代码入口见 [应用与数据设计](docs/10-application-design.md)。

## 工程目录

```text
degree-cert-system/
├── backend/           Flask 应用、模板、静态资源、测试及离线依赖
├── contracts/         第一版 Go 核心合约、测试和离线构建依赖
├── config/            Ubuntu 本机 CMC 配置，身份材料不放入交付包
├── instance/          Ubuntu 本机身份、部署记录、账号与 SQLite 数据
├── scripts/           环境、链、合约、网页安装与启动脚本
├── reports/           Ubuntu 检查报告
└── docs/              分步操作说明与设计记录
```

网页使用 Waitress 监听 Ubuntu 的 `127.0.0.1:8080`，无需 Node.js 或前端构建。提供三角色登录、工作台、签发、查询、详情、JSON 导出和核验、监管撤销、待确认交易查证与操作日志。网页运行不需要 sudo。
