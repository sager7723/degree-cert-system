# 第 1 步：放置项目与检查环境

本步骤确认 Ubuntu、Go、Python、Docker、CMC 和现有长安链文件的位置。先核对实际环境，再决定如何构建和部署，避免套用去年不匹配的命令。

已有资料的指导书写的是长安链 2.3.4、Go 合约、DOCKER_GO 运行时；这不代表当前虚拟机也是这个版本。合约 SDK 和链各有自己的版本号。

更完整的 `code.zip` 正式答辩版将作为重构主参考：其 Go 模块声明 Go 1.20、合约 SDK v2.3.2，并通过 `replace` 依赖本地 `../contract-sdk-go`；压缩包没有附带这个 SDK 目录。检查时需确认虚拟机是否已有可复用的模块和构建环境，不直接混用指导书中的 SmartIDE 构建方式。

## 1. 把项目放进 Ubuntu

Windows 资料目录下已建立 `degree-cert-system` 文件夹。请复制整个文件夹到 Ubuntu 文件管理器的“主文件夹”，对应路径 `/home/wsc`，完成后脚本位置应当是：

```text
/home/wsc/degree-cert-system/scripts/01-check-environment.sh
```

如果虚拟机已支持拖放或复制粘贴，可直接通过文件管理器传入。若使用共享文件夹，把共享目录中的 `degree-cert-system` 复制到 Ubuntu 的主文件夹。若两种方式都不可用，可以先执行本文件末尾的“不能传文件时的临时检查”，反馈结果后再安排传输。

不必复制 `chainmaker-go`、`chainmaker` 等已有工具目录到新项目，也不用复制整个旧资料文件夹。

## 2. 打开 Ubuntu 终端执行

下面全部命令在 `wsc@MXCZ` 的 Ubuntu 终端执行，不是在 Windows PowerShell 中执行。不要复制终端提示符 `wsc@MXCZ:~$`。

```bash
cd /home/wsc/degree-cert-system
pwd
ls scripts/01-check-environment.sh
bash scripts/01-check-environment.sh
```

`pwd` 应显示 `/home/wsc/degree-cert-system`。最后一条会打印检查内容，并在 `reports` 目录保存一份带时间戳的文本报告。请等到终端重新出现提示符；通常几十秒，检查超时时可能需要几分钟。

脚本只写入新项目的报告文件，不需要 `sudo`，不安装依赖，不启停 Docker 或链，不部署合约。缺少工具或权限时会记录后继续。报告不读取私钥、证书正文或完整配置内容。

如果 `cd` 或 `ls` 提示不存在，请先修正复制位置，避免出现两层 `degree-cert-system/degree-cert-system`。

如果文件曾通过 Windows 编辑器重存并出现 `$'\r'` 或 `invalid option`，先转换换行再运行：

```bash
sed -i 's/\r$//' /home/wsc/degree-cert-system/scripts/01-check-environment.sh
bash /home/wsc/degree-cert-system/scripts/01-check-environment.sh
```

原交付脚本已经采用 LF 换行，正常复制无需转换。

## 3. 把检查报告反馈到对话

在 Ubuntu 文件管理器中进入 `/home/wsc/degree-cert-system/reports`，打开刚生成的 `environment-日期-时间-随机字符.txt`，复制其完整文本发回即可。报告中 `未找到`、`permission denied` 等原样保留，下一步会据此处理。

当前结论仅是环境清单：目录存在、程序能显示版本或端口在监听，都不代表链已经能成功执行交易。下一步会核对实际配置、链身份和 DOCKER_GO 运行状态，再做真实的链查询与最小合约验证。

## 不能传文件时的临时检查

如果暂时不能把文件夹复制进 Ubuntu，可先完整粘贴执行下面这个命令块。它只建立新项目的报告目录并收集基础信息；这不是完整检查脚本，后续仍需补齐项目文件和链配置位置。若某条提示未找到命令，继续执行剩余项。

```bash
mkdir -p /home/wsc/degree-cert-system/reports
(
  printf '\n=== Ubuntu ===\n'
  cat /etc/os-release
  uname -m
  printf '\n=== Python / Go ===\n'
  python3 --version
  GOTOOLCHAIN=local go version
  printf '\n=== Docker ===\n'
  timeout 15s docker --version
  timeout 15s docker ps -a --format 'table {{.Names}}\t{{.Image}}\t{{.Status}}'
  printf '\n=== CMC ===\n'
  ls -l /home/wsc/chainmaker-go/tools/cmc/cmc
  printf '\n=== Listening ports ===\n'
  ss -lnt
) 2>&1 | tee /home/wsc/degree-cert-system/reports/first-check.txt
```

将输出发回即可。此临时报告重复运行会覆盖同名报告，不会修改已有链或源码。
